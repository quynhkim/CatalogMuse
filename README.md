# Catalog Muse

React + TypeScript + Vite app

Live Application Deployment: https://catalog-muse-demo.asinzen.com/

## Scripts

```bash
cp env.development .env.development
npm install
npm run dev
```

`npm run dev` serves the app with the development API. `npm run build` produces the production bundle in `dist/`.

Every environment calls `https://catalog-muse-api.asinzen.com`.
